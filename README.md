# 🎓 EduMate — Smart University Management System

> Graduation Project | UI/UX Design | Mobile App + Admin Dashboard

## 📌 Overview
A comprehensive smart university management system designed entirely in Figma — covering the full student and admin experience from course registration to AI-powered support.

## ✨ Features
| Feature | Description |
|---------|-------------|
| 📚 Course Management | Register, drop, and track courses with class stream |
| 🤖 AI Chatbot | Instant answers based on your lecture materials |
| 📍 Location-based Attendance | Auto attendance via GPS |
| 📊 GPA Tracking | Real-time academic performance & yearly progress |
| 🎓 Graduation Projects | Discover & join graduation project teams |
| 🖥️ Admin Dashboard | Full control: students, doctors, TAs & requests |

## 📱 Screens
| Screen | Description |
|--------|-------------|
| Home | Daily schedule with calendar view |
| Courses | Class stream with announcements & materials |
| EduMate AI | AI chatbot for lecture summaries & Q&A |
| Attendance | Location-based attendance submission |
| Graduation | Project teams discovery & joining |
| Profile | GPA, credit hours & academic info |
| Admin | Dashboard with stats & approval requests |
