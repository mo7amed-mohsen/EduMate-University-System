# 🎓 EduMate — Smart University Management System

> Graduation Project | UI/UX Design | Mobile App + Admin Dashboard

## 📌 Overview
A comprehensive smart university management system designed entirely in Figma — covering the full student and admin experience from course registration to AI-powered support.

## 🛠️ Tools
![Figma](https://img.shields.io/badge/Figma-F24E1E?style=for-the-badge&logo=figma&logoColor=white)

## ✨ Features
| Feature | Description |
|---------|-------------|
| 📚 Course Management | Register, drop, and track courses |
| 🤖 AI Chatbot | Instant student support |
| 📍 Location-based Attendance | Auto attendance via GPS |
| 📊 GPA Tracking | Real-time academic performance |
| 🖥️ Admin Dashboard | Full system control panel |

## 📱 Deliverables
- Mobile App UI (Student-facing)
- Admin Dashboard (Web-based)
- Complete Design System
